# Mohankumar S — Portfolio

A responsive, dark-themed student portfolio built with HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — colours, layout, responsive styling
- `script.js` — mobile navigation and current year

## Run locally
Open `index.html` in a browser, or open the folder in VS Code and use a local preview extension.

## Publish with GitHub Pages
1. Create a GitHub repository named `YOUR-USERNAME.github.io` (replace `YOUR-USERNAME` with your GitHub username).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under the build/deployment section, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for the deployment to finish. Your site will be at `https://YOUR-USERNAME.github.io/`.

## Before publishing
- Replace the generic GitHub and LinkedIn URLs in `index.html` with your own profile URLs.
- Update the project links after you create the repositories.
- Add a real profile photo only if you want one; the current avatar is initials.
- Keep skills accurate and change project status from starter/planned only when appropriate.

## Editing later
Edit the files and upload/commit the changes to GitHub. GitHub Pages will publish the updated site after deployment.
